# 商店分類與穿戴修正

本輪依 2026-10-21 的使用者選擇製作，先供本機試閱。

## 行為

- 已購商品點選後自動儲存穿戴；再次點選則明確脫下並儲存。
- 未購商品只影響試穿模型。取消試穿會露出該部位原本的衣著；原本沒有衣著則保持空著。
- 購買其他部位的商品時，不會因為正在試穿未購商品而清除原有衣著。
- 儲存期間避免重複寫入；按商店返回鍵會等儲存完成。若儲存失敗，留在商店並顯示錯誤，保留重試動作。
- 首頁較早發出的造型讀取若晚於商店儲存返回，會忽略舊結果。
- 離線時可試穿，但不會宣稱造型已儲存；連線後可再按「穿上」。

## 商品排列

全部 220 件商品依眼睛、眼鏡、單耳環、眉環、項鍊、帽子、圍巾／披肩、胸針、嘴邊小物、吊飾、身體材質歸位，每件只出現一次。每個部位內按價格排列，新舊商品混合展示。

國家、系列與只看已擁有收進底部篩選面板，可交叉套用；切換其中一項不會重設其他條件。卡片區分「已擁有」、「穿戴中」與「試穿中」。預設不再用新系列單獨佔一排分類。

保留上方 3D 試穿台及既有捲動縮放。圖片維持延遲載入，沒有新增逐幀 React 更新。
